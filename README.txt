AGENT MINA v0.1 — УСТАНОВКА

СОДЕРЖИМОЕ
- index.html
- styles.css
- app.js
- manifest.json
- sw.js

КАК УСТАНОВИТЬ НА GITHUB PAGES
1. Сначала сделай резервную копию старого репозитория или скачай старые файлы.
2. Открой свой репозиторий GitHub.
3. Замени старые index.html и app.js новыми.
4. Добавь styles.css, manifest.json и sw.js.
5. Если старый CSS назывался style.css, новый файл должен называться именно styles.css — это указано в index.html.
6. Сохрани изменения (Commit changes) и дождись обновления GitHub Pages.
7. Открой сайт и перейди в Настройки.
8. Введи STUDIO_TOKEN от своего Cloudflare Worker и нажми «Проверить подключение».
9. Напиши Мине сообщение.

ВАЖНО
- Worker URL по умолчанию: https://ai-video-brain.tolasovalihan9.workers.dev
- Используется существующий маршрут POST /ai/test.
- В запросе передаётся JSON { "prompt": "..." } и заголовок Authorization: Bearer STUDIO_TOKEN.
- Сам токен не вставляй в app.js, GitHub или публичные файлы. Введённый токен хранится только в памяти вкладки.
- История чатов хранится в localStorage браузера на устройстве.
- Для проверки подключения Worker должен разрешать CORS-запросы с домена GitHub Pages. Если появится CORS error, потребуется поправить Worker.
- В этой версии ИИ не управляет Android-приложениями и не имеет прямого доступа к файлам телефона. Это добавим отдельным Android-компаньоном.

Если сайт раньше был установлен как PWA и показывает старую версию:
1. Закрой установленное приложение.
2. Открой сайт в браузере и обнови страницу.
3. Если всё ещё старая версия, очисти данные сайта/кэш браузера для GitHub Pages и открой снова.
